데이터베이스에서 원하는 정보를 얻기 위해 가장 많이 사용하는 기술이 바로 **조인(JOIN)**입니다. 흩어져 있는 테이블들을 하나로 묶어 의미 있는 데이터를 만들어내는 조인의 다양한 방식들을 완벽하게 이해해 보겠습니다.

### 1. 조인의 기본 개념
조인은 두 개 이상의 테이블을 연결하여 데이터를 출력하는 기술입니다. 크게 연산 방식에 따라 다음과 같이 나뉩니다.
*   **EQUI JOIN (등가 조인):** 두 테이블의 컬럼 값이 정확히 일치하는 경우를 연결합니다. (`=`)
*   **Non EQUI JOIN (비등가 조인):** 부등호나 `BETWEEN` 같은 연산자를 사용하여 일치하지 않는 범위를 연결합니다.

### 2. 표준 JOIN 형태 (FROM절)
*   **INNER JOIN:** 교집합과 유사하며, 조인 조건에 맞는 데이터만 출력합니다.
*   **NATURAL JOIN:** 이름과 데이터 타입이 같은 모든 컬럼을 자동으로 조인합니다. (`USING`이나 `ON` 절을 쓸 수 없습니다.)
*   **USING 조건절:** 같은 이름을 가진 컬럼 중 특정 컬럼만 조인 조건으로 선택할 때 사용합니다.
*   **OUTER JOIN:** 조인 조건에 맞지 않는 데이터도 포함하여 출력합니다.
    *   `LEFT OUTER JOIN`: 왼쪽 테이블의 모든 데이터 유지
    *   `RIGHT OUTER JOIN`: 오른쪽 테이블의 모든 데이터 유지
    *   `FULL OUTER JOIN`: 양쪽 테이블의 모든 데이터 유지
*   **CROSS JOIN:** 두 테이블의 모든 가능한 조합(카티션 곱)을 생성합니다.

### 3. 특수한 조인: Self JOIN
하나의 테이블 내에서 서로 다른 별칭(Alias)을 부여하여 자기 자신과 조인하는 방식입니다. 조직도(사원-관리자 관계) 같은 계층형 데이터를 다룰 때 유용합니다.

---
조인은 SQL의 꽃이자 성능 최적화의 핵심입니다. 각 조인 방식이 어떤 결과를 내는지 정확히 파악하고, 상황에 맞는 가장 효율적인 조인문을 작성하는 연습이 필요합니다.
