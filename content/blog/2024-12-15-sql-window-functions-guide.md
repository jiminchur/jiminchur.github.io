데이터 분석을 하다 보면 현재 행의 값뿐만 아니라 이전 행의 값, 혹은 전체 그룹 내에서의 순위나 비율이 필요한 경우가 많습니다. 이때 강력한 힘을 발휘하는 것이 바로 **윈도우 함수(Window Function)**입니다.

### 1. 윈도우 함수의 기본 구조
윈도우 함수는 `OVER` 절을 반드시 동반하며, 집계 결과가 단일 행으로 줄어들지 않고 원본 행의 개수를 유지한다는 특징이 있습니다.
```sql
SELECT 함수(컬럼) OVER (PARTITION BY ... ORDER BY ... WINDOWING 절)
```

### 2. 순위와 비율 함수
*   **RANK / DENSE_RANK / ROW_NUMBER:** 중복 순위 처리 방식에 따라 나뉘는 순위 함수들입니다.
*   **PERCENT_RANK / CUME_DIST:** 백분율 순위와 누적 분포를 계산합니다.
*   **NTILE:** 전체 데이터를 N개의 그룹으로 균등하게 나눕니다.
*   **RATIO_TO_REPORT:** 그룹 내 전체 합계 대비 현재 행의 비율을 구합니다.

### 3. 행 순서와 집계 함수
*   **LAG / LEAD:** 현재 행을 기준으로 이전(`LAG`) 또는 다음(`LEAD`) 행의 값을 가져옵니다. 추이 분석에 필수적입니다.
*   **FIRST_VALUE / LAST_VALUE:** 윈도우 범위 내에서 가장 첫 번째 값이나 마지막 값을 가져옵니다.
*   **집계 윈도우 함수:** `SUM`, `AVG`, `MAX`, `MIN`, `COUNT` 등을 `OVER` 절과 함께 사용하여 누적 합계나 이동 평균을 계산할 수 있습니다.

---
윈도우 함수는 복잡한 셀프 조인이나 서브쿼리 없이도 고난도의 데이터 분석을 가능하게 해줍니다. 특히 실무 통계 쿼리에서 생산성을 비약적으로 높여주는 도구이므로, 각 함수의 동작 방식을 정확히 숙지해 두시기 바랍니다.
