애플리케이션을 배포할 때마다 환경 설정 때문에 골머리를 앓고 있다면, 도커(Docker)가 그 해답이 될 수 있습니다. 설치부터 복잡한 환경을 하나의 파일로 정의하는 Dockerfile, 그리고 여러 컨테이너를 한꺼번에 띄우는 Docker Compose까지 핵심적인 내용들을 살펴보겠습니다.

### 1. Dockerfile: 이미지 빌드의 설계도
Dockerfile은 기존에 수동으로 하던 패키지 설치, 환경 설정, 소스 코드 복사 등의 과정을 기록한 파일입니다. 이를 빌드하면 실행 가능한 '이미지'가 생성되며, 배포 프로세스를 완벽하게 자동화할 수 있습니다.

*   **주요 명령어:**
    *   `FROM`: 베이스 이미지 지정 (예: `ubuntu:14.04`)
    *   `RUN`: 이미지 빌드 시 실행할 명령 (패키지 설치 등)
    *   `ADD` / `COPY`: 호스트의 파일을 이미지로 복사
    *   `WORKDIR`: 작업 디렉토리 설정
    *   `EXPOSE`: 개방할 포트 지정
    *   `CMD`: 컨테이너가 시작될 때 실행할 기본 명령

### 2. Docker Compose: 다중 컨테이너 관리
웹 서버, 데이터베이스, 캐시 서버 등 여러 개의 컨테이너를 하나로 묶어 관리해야 할 때 사용합니다. `docker-compose.yml` 파일에 각 서비스의 설정을 정의하고 `docker-compose up` 명령 한 번으로 전체 환경을 띄울 수 있습니다.

### 3. 권한 관리 및 팁
리눅스 환경에서 도커를 사용할 때 매번 `sudo`를 붙여야 하는 번거로움을 피하려면, 현재 사용자를 `docker` 그룹에 추가하는 설정이 필요합니다.
```bash
sudo usermod -aG docker $USER
```
이후 로그아웃 후 다시 접속하면 권한 문제 없이 도커 명령어를 실행할 수 있습니다.
